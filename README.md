# Тестовое задание GreenAPI

## Технологии:

React, Redux Toolkit, React Router, TypeScript, Vite.

## Инструкция к установке и локальному запуску:

В данном проекте используется пакетный менеджер **npm** версии **11.5.2**. В корне проекта выполнить:

```bash
npm i
```

После установки зависимостей из **package.json** можно запустить локально из корня проекта:

```bash
npm run dev
```

и перейти по адресу из консоли.

## Суть проекта:

Данный проект включает в себя форму входа, куда вводятся данные *(idInstance, apiTokenInstance)* из сервиса **GreenAPI**. После можно ввести номер адресата и начать переписку.
